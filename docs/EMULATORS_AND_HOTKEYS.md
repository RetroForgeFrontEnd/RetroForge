# Emulators and hotkeys

Status (2026-10-28): built; emulator tested where stated.

## RetroArch cores

`RetroArchCores` offers hand-picked cores first (chosen for phones, e.g. SwanStation for PS1), then RetroBat's own choices for the system where libretro builds the core for Android (`RetroArchCoreTable.kt`, generated by `tools/gen_cores.py` from RetroBat's `es_systems.cfg` and the libretro Android buildbot list). 91 of the 121 systems in the RetroBat collection have one. See [SYSTEM_COVERAGE.md](SYSTEM_COVERAGE.md).

## Free standalone emulators

21 free apps (DuckStation, Dolphin, PPSSPP, Azahar, melonDS, NetherSX2, ARMSX2, Flycast, Redream, M64Plus FZ, Eden, MAME4droid …) for 56 systems, with ES-DE's Android launch commands (MIT; `tools/gen_standalone.py`). On a game's page: Play with an installed one, make it the system's default, or Get it — Obtainium's add screen when the emulator publishes releases Obtainium can track, otherwise the official page. RetroForge never downloads or installs emulators.

The game file is passed as a content:// URI with read access granted to that emulator only. Multi-file games (.cue, .m3u) usually also need the folder added inside the emulator; the page says so.

Evidence: parsing unit-tested (DuckStation, Dolphin, PPSSPP, MAME4droid); **PPSSPP 1.20.4 launch-tested** on the emulator (Pinball Dreams .cso reached its table select; default choice and play history work). Other standalone emulators not tested yet (most are ARM64-only and need a real phone).

## RetroArch hotkeys, fast-forward and resume

Android doesn't let one app read the controller while another is on screen, so in-game hotkeys must be the emulator's own. For RetroArch, RetroForge writes `Documents/RetroForge/retroarch-retroforge.cfg` and passes it as RetroArch's config: RetroForge's settings first, then `#include` of RetroArch's own `retroarch.cfg` (RetroArch reads top down and, when saving, writes changed settings above the include, so the user's own config is never edited). Settings used, checked against RetroArch 1.22.2 source:

| Setting | Value | Meaning |
|---|---|---|
| `input_quit_gamepad_combo` | 4 (Start + Select, changeable) | Quit back to RetroForge |
| `input_menu_toggle_gamepad_combo` | 9 (Down + Select, changeable) | RetroArch menu |
| `quit_press_twice` | false | Quit at once |
| `input_hold_fast_forward_btn` | 105 (KEYCODE_BUTTON_R2) | Hold R2 to fast-forward — only for systems whose controllers had no R2 |
| `savestate_auto_save` / `savestate_auto_load` | on (Settings switch) | Carry on where you left off |

Evidence (emulator): file written; RetroArch's own menus show Down + Select, Start + Select, "Confirm Quit" off and "Fast-Forward (Hold): Button 105"; closing a SNES game wrote `.state.auto` and the next launch reported "Auto-loading save state … succeeded". **Not tested with a physical controller** (combos and R2 need one); a pad that reports R2 only as an analog trigger may not trigger fast-forward. Disc swap has no RetroArch combo setting: use the menu's Disc Control. Needs Android 10+.

Settings → Hotkeys lists every hotkey.
