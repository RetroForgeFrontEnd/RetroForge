# RetroForge privacy policy

Effective 2026-10-28 (beta). Publish this page (for example on GitHub Pages) before listing RetroForge on Google Play; the in-app copy is under Settings → Privacy.

**In short: RetroForge collects nothing about you. It has no accounts, no analytics, no ads and no tracking.**

## What stays on your device

Your library index, play history, favourites, playlists, chosen covers, settings, themes, ROM manager history and any API keys or logins you add are stored only in RetroForge's private storage on your device. They are never sent to the RetroForge developer. Uninstalling RetroForge deletes them. Device backup is turned off for this data.

## When RetroForge connects to the internet

Only for things you start, and only to these services:

| Service | When | What is sent |
|---|---|---|
| libretro thumbnails (thumbnails.libretro.com) | Downloading box art | The system's folder name and game names in the address |
| SteamGridDB (steamgriddb.com) | You search covers there | The search text and your own API key |
| ScreenScraper (screenscraper.fr) | You press "Look up on ScreenScraper" | The game's file name, size and checksum, RetroForge's developer ID and, if you added it, your ScreenScraper login |
| A hack catalogue address you added | You add or refresh that catalogue | A normal web request |

Each service has its own privacy policy. Opening a link (an emulator's download page, a hack's page, a YouTube channel) hands it to your browser.

## Files

RetroForge reads the game folders you choose. It changes files there only when you confirm a ROM manager action, and it never uploads them anywhere.

## Contact

Report problems or questions through the project's GitHub Issues page.
